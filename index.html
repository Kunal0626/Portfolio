    ▣ CHAINLOG.BIN

    DATA INTEGRITY

    ChainLog

    A tamper-evident audit log engine in C++. Every record is hash-chained and batched into a Merkle tree, so any edit, deletion or reordering of history is detectable, with O(log n) inclusion proofs.

    ▣ SANDBOXLITE.BIN

    OPERATING SYSTEMS

    SandboxLite

    A Linux sandbox that runs untrusted binaries under ptrace and seccomp, logs every system call and blocks anything outside a per-program allowlist. A Python report flags runs that deviate from a learned syscall baseline.

    ▣ QUERYSHIELD.JAR

    WEB & DATABASE SECURITY

    QueryShield

    A Java reverse proxy that screens requests for SQL injection with a SQL tokenizer and an Aho–Corasick multi-pattern matcher, scanning payloads in linear time. Tested in front of a deliberately vulnerable MySQL-backed app; on a 205-payload held-out test set it reached 100% detection at a 2.1% false-positive rate.

    • Java
    • SQL
    • MySQL
    • Aho–Corasick
    GitHub
    ▣ CHOKEPOINT.PY

    GRAPH ALGORITHMS

    ChokePoint

    An attack-path and patch-priority analyzer. It models a network as a weighted graph, uses Dijkstra to find the cheapest attacker route to a critical asset, then max-flow / min-cut to find the smallest set of fixes that severs every path.

    • Python
    • Dijkstra
    • Max-Flow
    • Min-Cut
    GitHub

    THREAT INTELLIGENCE

    ShadowPot

    A Cowrie-based SSH honeypot with analytics on top. Session logs go into a normalized SQL schema, and queries on credentials tried, source IPs and post-login commands show how attackers actually behave.

    • Python
    • Cowrie

    ▣ RESNAV.SQL

    FULL-STACK / DBMS

    ResNav — Disaster Resource Allocation

    Full-stack relief logistics where the database is the source of truth. A React console calls a Flask API, but the allocation itself runs inside MySQL: a stored procedure takes row locks in a fixed order and assigns the nearest relief centre with stock, so two dispatchers cannot promise the same units. Ten triggers and twenty-two constraints hold the invariants; two-session tests prove the race is gone.

    • MySQL
    • Stored procedures
    • Triggers
    • Concurrency
    • Flask
    • React
